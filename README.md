# 我的挫折思考小測驗（前測）

國中國文閱讀教學行動研究使用的線上前測。學生選一個生活故事，回答六題開放式問題，答案自動寫入 Google 試算表。

- 學生網址：`https://littlejocelyn2-hfjh.github.io/frustration-pretest/`
- 教師區：學生網址後加 `#teacher`
- 大屏：教師登入後按「開啟大屏」（或網址加 `#screen`）

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 學生作答頁、教師區、大屏 |
| `config.js` | 填入 Apps Script 的 `/exec` 網址（留空＝本機模式，只存在該裝置） |
| `apps-script/Code.gs` | 貼到 Google Apps Script 的後端 |

## 一、開啟 GitHub Pages

Settings → Pages → Source 選 **Deploy from a branch** → Branch 選 **main / (root)** → Save。約 1 分鐘後網址生效。

## 二、部署 Apps Script（後端）

1. 新增一份 Google 試算表 → 擴充功能 → Apps Script。
2. 刪掉預設程式，貼上 `apps-script/Code.gs` 全部內容。
3. **第 8 行**把 `change-me` 改成你的教師密碼（保持 `change-me` 會一律無法登入）。密碼只存在 Apps Script，不會出現在 GitHub。
4. 儲存 → 上方函式選 `setupSheet` → 執行 → 依指示授權。試算表會出現「前測資料」與「題目對照」兩個工作表。
5. 部署 → 新增部署作業 → 類型「網頁應用程式」→ 執行身分：**我**；誰可以存取：**所有人** → 部署。
6. 複製 `/exec` 網址，填到 `config.js` 的 `sheetApi`（或交給 Claude 填入並推送）。

直接打開 `/exec` 網址看到 `{"ok":true,...}` 是正常的，那是後端。

**之後若修改 Code.gs**：重新貼上 → 再改一次第 8 行密碼 → 部署 → 管理部署作業 → 鉛筆 → 版本選「新版本」→ 部署。網址不變。

## 三、試算表欄位（工作表「前測資料」）

提交時間｜班級｜座號或研究代碼｜情境代號｜情境標題｜選擇原因代號｜選擇原因｜其他原因說明｜Q1–Q6 原始回答｜開始作答時間｜作答秒數｜裝置｜提交ID｜版本｜備註

- 不論選哪個情境，六題都在固定欄位。
- 每份作答有提交ID，重複送出或重複匯入都只會有一筆。
- 同班同座號已有資料時，「備註」欄自動標記（不擋下）。
- 學生文字以 `= + - @` 開頭時不會被當成公式。
- 「題目對照」工作表列出各欄位的完整題目、情境與原因代號。

## 四、老師怎麼看資料

- 教師區（`#teacher`）輸入密碼，密碼由後端驗證。
- 可依班級、情境、座號篩選；點一列展開六題完整回答；「複製到 Excel」可直接貼上。
- 提醒標記：作答總時間低於門檻（預設 180 秒，可調）或六題都少於 3 字。**只是提醒，請老師自行確認**，不代表答案不好。
- 學生無法送出時會拿到一段「作答碼」（PT1: 開頭），老師可在教師區「匯入學生的作答碼」補登。
- 大屏只顯示「幾位同學已完成」與已完成的座號，不顯示任何作答內容或情境分布（避免影響其他學生選擇）。

## 五、測試清單

1. Apps Script 編輯器執行 `testSubmit`：四個情境各寫入一筆、重複送出回傳 `duplicate:true`、缺題被擋下。測完刪掉 TEST 列。
2. 用手機打開學生網址（Ctrl+F5 / 重新整理），用假班級 `TEST` 完整做一次，確認試算表多一列、六題都有內容。
3. 教師區輸入錯誤密碼應失敗，正確密碼可看到剛才那筆。
4. 開大屏，確認完成人數有更新。
5. 正式施測前刪除所有測試資料（保留第 1 列）。

## 研究設計原則

本前測未進行教學介入：不出現課文、不提示「挫折使人成長」、不引導正向思考、不提供範例答案、作答中不給內容回饋，「不再嘗試」不被視為負面答案。完成畫面不顯示評價或分析。
